# Legacy Files Archive

This directory contains legacy implementation files preserved from the initial project prototype:

- `Datarecive.py`: Early MQTT test subscriber. Replaced by `app/mqtt/subscriber.py`.
- `Datatransmit.py`: Early MQTT test publisher. Replaced by `app/mqtt/publisher.py`.
- `database_viewer.py`: Simple database print script. Replaced by `scripts/view_database.py`.
- `main.py`: PyCharm boilerplate template script.
- `sensorsimulator.py`: Initial single-file sensor randomizer. Replaced by `app/simulator/sensor_simulator.py`.
